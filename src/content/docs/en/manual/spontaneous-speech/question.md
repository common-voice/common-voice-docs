Only moderators can use this page. Others see "Not enough rights to use this action". The parts every contribution page shares are on [the contribution page](../common-parts.md#contribution-page).

## Add questions {#add}

- ① Type your questions, one on each line.
- ② This shows how many questions you can add at once.
- ③ Choose up to three domains, if they fit. This is optional.
- ④ Press **Submit**.

![The Question page, with the questions ①, the limit ②, the domain ③ and Submit ④](../../../images/en/manual/spontaneous-speech/question-desktop-light.png)

## Tips {#tips}

- Ask about everyday life, not about private things.
- Keep each question short and easy to answer.
- Rules for questions: [Question Collection](../../contribute/guidelines/questions.md).
