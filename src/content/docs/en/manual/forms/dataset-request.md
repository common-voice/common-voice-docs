Your language is not in a section yet? Ask for it. A dataset is one language in one section.

## Make a request {#request}

- It has three steps: **Language**, **Review** and **Additional info**.
- ① The bar shows which step you are on.
- ② Search among the existing languages, and pick yours.
- ③ Press **Next**.

![The Request a dataset form, with the steps ①, the language ② and Next ③](../../../images/en/manual/forms/dataset-request-desktop-light.png)

## Where to find it {#where}

- Open the Scripted Speech page, then use **Request a dataset**. Requests are open for Scripted Speech only: [Start here, step 4](../index.md#dataset).
- More about requests: [Request a dataset](../../languages/dataset-request.md).
